# Mi proyecto de Base de Datos
Este proyecto es un ejemplo sencillo de una base de datos para una biblioteca.

# Herramientas utilizadas
Visual Studio Code, Git, GitHub y CapCut.

# Organización del grupo 
Como eramos tres, hicimos un guíon (verificamos que todo estaba bien) y luego lo repartimos en tres partes. 

# Problemas que tuvimos durante la grabación
El primer problema que tuvimos fue que dos integrantes del grupo se encontraban enfermas al momento de realizar la grabación =/ , lo segundo es que teniamos un error con un comando pero lo supimos arreglar (estaba relacionado con guardar un commit en la rama main), y por último el tema de editar ya que ninguna de las integrantes es muy buena en eso.
